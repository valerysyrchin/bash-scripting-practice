# FreeCodeCamp: Bash Scripting Practice

[Русское описание ниже](#описание-проекта-на-русском)

A collection of small Bash scripts and mini-projects developed during the freeCodeCamp workshop. This repository demonstrates core and advanced process automation skills within the Unix/Linux environment.

### Mini-Projects Overview
The repository includes the following utilities:
* **Bingo Number Generator** — a dynamic numbers generator for Bingo games (focused on random number generation).
* **Fortune Teller** — an interactive fortune-telling simulator (exploring conditional logic and randomization).
* **Countdown Timer** — a countdown script utilizing loops (focused on time management and standard terminal output control).
* **Questionnaire** — an interactive polling script that collects user inputs and logs them directly to a text file.
* **Five Program** — a demonstration script showcasing various methods of handling command-line arguments and loops.

### Key Achievements & Skills Practiced:
* **Variables:** Creating, reading, and dynamically modifying environment and custom data.
* **Arrays:** Managing data lists, storing collections, and iterating through elements.
* **Conditionals:** Implementing control flow via `if`/`elif`/`else` blocks and comparison operators (`[[ ... ]]`).
* **Loops:** Automating repetitive tasks using `while`, `until`, and `for` loop structures.
* **Functions:** Modularity and clean code principles by splitting scripts into reusable logical blocks.
* **User Input:** Capturing interactive user responses via the `read` command and parsing positional parameters (`$1`, `$2`).

## Описание проекта на русском

Коллекция небольших Bash-скриптов и мини-проектов, созданных в рамках воркшопа по Bash-скриптингу от freeCodeCamp. Проект демонстрирует базовые и продвинутые навыки автоматизации процессов в среде Unix/Linux.

### Список мини-проектов внутри
Репозиторий включает в себя следующие программы:
* **Bingo Number Generator** — генератор чисел для игры в Бинго (работа со случайными числами).
* **Fortune Teller** — интерактивный симулятор предсказания судьбы (рандомизация и логика ответов).
* **Countdown Timer** — скрипт таймера обратного отсчета (работа со временем и управление выводом в терминал).
* **Questionnaire** — интерактивный опросник, собирающий ответы пользователя и записывающий их в файл.
* **Five Program** — скрипт, демонстрирующий различные способы работы с аргументами командной строки и циклами.

### Ключевые навыки и концепции:
В ходе написания этих утилит были закреплены следующие возможности командной оболочки Bash:
* **Переменные (Variables):** создание, чтение и динамическое изменение данных.
* **Массивы (Arrays):** хранение списков элементов и итерация по ним.
* **Условные операторы (Conditionals):** использование конструкций `if`/`elif`/`else` и операторов сравнения (`[[ ... ]]`).
* **Циклы (Loops):** перебор данных с помощью `while`, `until` и `for`.
* **Функции (Functions):** разбиение кода на повторно используемые логические блоки.
* **Ввод пользователя (User Input):** интерактивный перехват ответов через команду `read` и обработка позиционных параметров (`$1`, `$2`).
